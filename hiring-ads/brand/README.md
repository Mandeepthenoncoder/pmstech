# Brand assets

Drop the real files here before asking for ads. Claude places these files as they
are and never redraws, recolours or regenerates a logo.

If a folder is empty, Claude will say so rather than invent something.

## What goes where

### `purple-magic/`
- [x] `logo-mark.svg` — already here
- [ ] Wordmark, if there is one separate from the mark
- [ ] A light version, for use on white

### `mangatrai/`
- [x] `mangatrai-logo.png` — already here, light on dark
- [ ] A dark version for light backgrounds
- [ ] Vector, if you have it. Better than PNG for large type sizes.

### `the-lab/`
- [ ] **Missing.** The LAB by Mangatrai logo, from the brand deck.
      Two of the six roles are for this brand, so ads for them cannot be
      finished until this is here.
- [ ] Dark and light versions

## Fonts

Named in BRIEF.md. If a licensed font file is needed rather than a Google Font,
put it in a `fonts/` folder here.

## File naming

`<brand>-logo-<variant>.<ext>`, for example `the-lab-logo-light.svg`.
