# Reference

Anything that should steer the look, rather than be copied.

Useful things to put here:

- Photos of the Kokapet and Baseerbagh stores
- Real product photography, if any ad should carry a product
- Screenshots of past ads that performed, and ones that did not
- A page or two from the brand deck

Name files so the purpose is obvious: `kokapet-store-interior.jpg`,
`past-ad-worked-diwali.png`.

Claude will not generate jewellery images. AI gets stone counts and settings
wrong, and these are real products. If an ad needs a product in it, the photo
has to come from here.
